Enable Copy Individual Trigger Lines and open a trigger for editing. Use Copy line on a condition or action. In the destination trigger, choose Paste before or Paste after on the target line. For an empty clause, use Paste first IF or Paste first THEN beside the native Add control when available. The editor must expose an editable, empty collection for this operation. Both triggers must be in the same app version and tab. The clipboard survives step navigation in that tab.

The adapter requires a rendered row with a model ID and a controlled editable list or clause. It inserts a fresh row ID and checks for the new row after rendering. Source-specific event/widget bindings and transitions stay in their native editor. Verify the data source, target variable and order after a save and reopen on each supported Tulip release.
