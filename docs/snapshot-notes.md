Automatic Snapshots counts focused, active editor time. Set the interval and optional note under its popup switch. Each editor version has its own clock. The native snapshot dialog must be available.

The description lists added, removed and renamed app assets for named collections that the open editor supplies. It prefers a visible previous snapshot model when available. Otherwise a confirmed manual or automatic snapshot observed by this extension establishes the local comparison. Descriptions name the coverage. Colors, coordinates and runtime record values are excluded.

A native success notification confirms a submission. An ambiguous submission pauses automatic attempts for that version to avoid duplicates. A confirmed manual snapshot resumes timing. You can also check the Versions history and choose Resume timer. That starts a fresh comparison baseline. Check the actual Versions history when testing a new Tulip release.
